# 历史人格研究所 · History Soul

一个中文浏览器小游戏：用 20 道日常情景题寻找历史同频人，也可以玩人物翻翻乐，收集自己的时空护照。

纯 HTML、CSS 和原生 JavaScript 模块，无框架、无服务端、无第三方运行依赖。`dist/` 同时包含可直接运行的站点与可编辑源码，不需要构建。

## 玩法

- **历史人格探索**：20 道题、5 个连续维度、72 位历史人物。支持返回修改、本机进度恢复、结果解释与备选人物。
- **人物翻翻乐**：每日挑战固定 6 对卡片，按北京时间零点更新；自由模式可选 6 对或 8 对，每次重开重新洗牌。翻开相同人物完成配对，每翻两张算一步；最佳成绩只保存在本机。
- **时空护照**：在当前浏览器保存人物收集记录，回看已经遇见的历史朋友。
- **人物图鉴与分享**：按人物、时代、别名或标签探索；保存含五维分数的 PNG 小卡，或分享只含人物编号的链接。
- **音乐与反馈**：原创 Web Audio 背景音乐与操作音效，支持音乐、音效和音量设置。浏览器限制自动播放时，首次有效操作后开始；主动静音的偏好会保留。

人物配图包含 71 位逐人生成的 AI 艺术肖像及 1 位原创 SVG 角色。它们是艺术诠释，不是真实容貌考证。来源与授权范围见 [ASSETS.md](ASSETS.md)。

## 本地运行

需要 Node.js 18 或更新版本（运行检查），以及 Python 3（启动静态服务器）。没有需要安装的 npm 依赖，也不需要 API key。

在仓库根目录运行：

```sh
npm test
npm start
```

也可以不使用 npm：

```sh
node tests.mjs
python3 -m http.server 4173 --directory dist
```

打开 [http://localhost:4173](http://localhost:4173)。不要直接双击 `index.html`：浏览器对 `file://` 下的 JavaScript 模块和分享能力有不同限制。按 `Ctrl+C` 停止服务器。

额外测试文件遵循 `tests*.mjs` 命名，可逐个执行 `node 文件名.mjs`，或运行 `node --test tests*.mjs`。测试用于检查计分、人物可达性、翻牌状态与音频生命周期；音频实际听感、触控与排版仍需要浏览器试玩。

## 操作

- 桌面：点击按钮和卡片；性格题支持数字 `1–4` 选择、Enter 继续。键盘 Tab 可移动焦点。
- 手机和平板：触摸选择、翻牌；页面保留正常滚动。
- 翻翻乐：第一次翻牌开始计时。暂停或切到后台的时间不计入成绩，返回后点击继续恢复本局。
- 音频：通过页面音频设置切换音乐、音效与音量。切到后台时暂停声音，返回后按浏览器能力恢复。
- 存档：答题进度、收集记录和音频设置只属于当前设备的当前浏览器；更换浏览器不会自动同步。

## 测评原理

题目借鉴大五人格的维度框架，但本项目的题目、中文表述、人物向量和解读均为原创趣味内容，**未经信度、效度或人群常模验证**。

每个维度有 4 题；选项在对应维度上记为 0、33、67 或 100，取平均后与人物的五维创作向量计算均方根距离。接近度是 `100 − 距离`，不是“你就是这个人”的概率、准确率或稀有度。人物向量不是历史人物接受心理测量后的结果，五维高低也不代表好坏。

结果适合聊天和自我观察，不用于心理诊断或重要的人事、医疗及关系决策。研究参考链接位于页面“测评原理”和 `dist/data.js`；本项目没有复制参考量表，也没有继承其测量效度。

## 隐私与分享

游戏逻辑在浏览器中运行。应用没有帐号、答题上传接口、分析 SDK 或跨设备存档；答案、进度、音频偏好与护照收藏保存在本机浏览器存储中。

- 结果链接的查询参数只有人物编号，例如 `?character=libai`，不包含答案或五维分数。
- 下载或分享的结果图片包含人物与五维分数，由玩家自行决定是否转发。
- 原生分享面板、剪贴板和文件下载由浏览器提供；应用不会自动向联系人发送消息。
- 网站托管方仍会处理正常页面请求，并可能提供登录或访问控制；本说明只描述游戏本身的数据处理。
- 清除浏览器站点数据会移除本机记录；已下载或已发给他人的图片不受影响。

## 运行与发布范围

公开源码可以自行部署到支持静态文件的托管服务，将 `dist/` 设为网站根目录即可。没有需要填写的服务端环境变量。

现有 [Sites 体验入口](https://history-soul-yl1105.yanglinchasel.chatgpt.site/) 使用私人访问控制，可能需要所有者登录；源码公开不等于该托管地址对公众开放。可公开访问的部署地址应以维护者后续实际公布的结果为准。

## 干净公开导出

在本地开发副本执行：

```sh
node scripts/export-public.mjs
```

脚本会创建新的临时目录并打印导出清单、SHA-256 和总大小。也可以用 `--out` 指定一个不存在或为空的目标目录。它只复制明确允许的源码、测试、文档和运行素材，并检查常见凭据及个人路径；它不会执行 Git 初始化、提交、上传、改仓库可见性或部署。
